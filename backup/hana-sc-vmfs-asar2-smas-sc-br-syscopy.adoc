== SnapCenter backup y recuperación y copia del sistema SAP HANA

[role="lead"]
NetApp SnapCenter optimiza las tareas del ciclo de vida de SAP HANA, como backup & recovery y la copia del sistema SAP HANA, y está integrado en la base de datos SAP HANA y en las herramientas de gestión del ciclo de vida, combinando una protección de datos eficiente e integrada en las aplicaciones con el aprovisionamiento flexible de sistemas de prueba de SAP, como se muestra en la siguiente figura.
