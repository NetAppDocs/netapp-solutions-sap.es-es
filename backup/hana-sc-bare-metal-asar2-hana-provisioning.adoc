En este capítulo se describe la instalación y configuración específicas del sistema SAP HANA BM1 utilizado para la documentación de esta solución. El sistema HANA QM1 se ha implementado de la misma manera.

Se puede encontrar información adicional sobre la implementación genérica y las mejores prácticas en https://docs.netapp.com/us-en/netapp-solutions-sap/bp/hana-asa-fc-introduction.html["SAP HANA en sistemas ASA de NetApp con el protocolo Fibre Channel"].

[[hana-host-configuration]]
== Configuración del host HANA

Antes de configurar el host, es necesario descargar las utilidades de host SAN de NetApp desde el sitio http://mysupport.netapp.com/["Soporte de NetApp"] e instalarlas en los servidores HANA. La documentación de las utilidades de host incluye información sobre el software adicional que debe instalarse en función del HBA FCP utilizado.

Las utilidades de host SAN de NetApp también pueden usarse para obtener el WWPN de los adaptadores de host necesarios para configurar la asignación de host en el sistema de almacenamiento.

....
sapcc-hana-tst-02:~ # sanlun fcp show adapter
host20             WWPN:100070b7e40bbadb
host21             WWPN:100070b7e40bbadc
....


[[multipath-configuration]]
=== Configuración multivía

. Ejecuta el comando rescan-scsi-bus.sh -a de Linux en cada servidor para detectar nuevos LUN.
. Ejecuta el comando «sanlun lun show» y comprueba que todos los LUN necesarios estén visibles. La salida muestra los LUN y los archivos de dispositivo correspondientes, que tienen cuatro rutas FC desde el host hasta los controladores de almacenamiento.

[[hana-installation]]
=== Instalación de HANA

Ahora puede ejecutarse la instalación de HANA.


NOTE: Con la configuración descrita, el directorio /usr/sap/BM1 se almacenará en el disco del sistema operativo. Si /usr/sap/BM1 debe almacenarse en un disco independiente, es necesario configurar un LUN adicional en el sistema de almacenamiento.
